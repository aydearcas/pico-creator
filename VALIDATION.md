# Validation / Verificación · 1.1.0

The read-only GitHub Actions workflow builds the standalone application and runs the complete automated test suite before distribution files are published.

Catalogue checks cover bilingual schema validation, clinical example structure, source cross-references, type-specific comparators, family/child selection, duplicate prevention, preservation of manual edits, canonical JSON save/load, version migration, template switching, safe input rejection, dropdown translation, visibility, undo and selected-only exports.

Real-browser visual layout, touch, native file picker, and Windows executable compilation remain manual checks. The catalogue is a non-exhaustive demonstration, with clinical limitations recorded in the file.
